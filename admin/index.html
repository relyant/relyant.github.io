GitHub Token nötig

Erstelle ein fine-grained personal access token:

  1. Token erstellen
  2. Repository access: Only select repositories → relyant.github.io
  3. Permissions: Contents → Read and write (Metadata wird automatisch gesetzt)
  4. Expiration: beliebig (z.B. 90 Tage)

Das Token bleibt in diesem Browser (localStorage) und wird nur direkt an api.github.com gesendet.
